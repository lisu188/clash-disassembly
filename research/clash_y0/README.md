# clash.y0.pl archive metadata

This directory contains reproducible metadata for the historical unofficial Clash site and forum at `clash.y0.pl`.

The raw site mirror is not committed. `tools/scrape_clash_y0.py` can recover archived bytes into an ignored local directory and records hashes/status in the tracked metadata. This keeps research provenance available without turning the public source repository into a mirror of third-party site content or game binaries.

See `docs/CLASH_DELUXE_RESEARCH.md` for the known history of Clash Deluxe 0.1 and the reverse-engineering workflow.
